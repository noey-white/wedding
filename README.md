# 주현 ♡ 지연 모바일 청첩장

GitHub Pages로 배포되는 모바일 청첩장입니다.

## 수정하는 곳
`index.html` 맨 아래 `CONFIG` 부분만 바꾸면 됩니다.

- `kakaoJsKey` : 카카오 개발자 JavaScript 키 (카카오톡 공유 카드용)
- `sheetApiUrl` : 구글 Apps Script 웹앱 주소 (참석 여부·방명록 저장용, `google-apps-script.gs` 참고)
- `accounts` : 계좌 정보
- `photos` : 갤러리 사진 경로 (`assets/photos/01.jpg` ~ `10.jpg`)

## 파일
- `assets/cover.jpg` 표지 사진
- `assets/og.jpg` 링크 미리보기 이미지 (1200×630)
- `assets/share.jpg` 카카오 공유 카드 이미지 (800×800)
- `assets/bgm.mp3` 배경 음악 (넣으면 자동 연결)
- `assets/wedding.ics` 아이폰 캘린더 추가용
